Page 2 • Fullstack

Product Detail Page (PostgreSQL API)

Halaman frontend dinamis yang terintegrasi langsung dengan server Express.js dan database PostgreSQL. Struktur data produk tersimpan terpusat dan persisten.

  • Database PostgreSQL (product_api → products)
  • Dynamic fetch GET /api/products/1
  • Auto-swatch varian ukuran 50 ml ($94.30) & 100 ml ($135.70)
  • Injeksi Description, More Info, & tabel Features 6 baris
  • State protection: tombol terkunci saat backend offline
  • Full REST API CRUD (GET, POST, PUT, DELETE)

Cara Menjalankan Backend Page 2 (PostgreSQL)

Pastikan container PostgreSQL Docker aktif, lalu jalankan backend:

cd J:\dibimbing\pdp-project\page-2\backend
npm start
# Server berjalan di http://localhost:3000

Data awal (Innoxa Unica AJ & Innoxa Radiance Serum) otomatis di-seed ke PostgreSQL saat server pertama kali dijalankan!
